# How to Use

## Getting Started

1. Visit [https://app.devmuthu.tech/login](https://app.devmuthu.tech/login)
2. Create an account with your email and a strong master password
3. Verify your email address
4. Log in to access your password vault

## Adding Passwords

1. Click **"Add Password"** on the dashboard
2. Fill in the service details
3. Use the password generator for secure credentials
4. Save to add to your vault

## Generating Passwords

1. Navigate to the **Generator** page
2. Adjust parameters to your needs
3. Click **"Generate Password"**
4. Copy or save directly to a new entry

---

## Technical Architecture

- **Frontend:** Angular with TypeScript  
- **Backend:** Node.js with Express  
- **Database:** MongoDB with encryption-at-rest  
- **Security:** AES-256 encryption, HTTPS, CSP headers  
- **Hosting:** Vercel (frontend), AWS (backend)

## Security Measures

- End-to-end encryption  
- Brute-force protection  
- Automatic logout after inactivity  
- No plaintext password storage
